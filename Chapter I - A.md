# Chapter I: Section A - Base Game Setup

## All the guides here are for Windows.

#### $\color{GreenYellow}{System\ Requirements}$
- The same as listed from [CS1.6 Steam Page](https://store.steampowered.com/app/10/CounterStrike/)
- Video card / graphics that supports DX11 and OpenGL 4.2+

#### $\color{GreenYellow}{Setting\ Up\ the\ Base\ Game}$
Choose between build 3266 or Latest version.

## $\color{Cyan}{[Build\ 3266\ or\ 8684\ (Steam/NoSteam)]}$ 
1. Download CS1.6 NoSteam build 3266 or 8684 from [here](https://csumods.blogspot.com/2023/05/counter-strike-16-no-steam-metahook.html), or buy the [Steam](https://store.steampowered.com/app/10/CounterStrike/) version (make sure to choose steam_legacy to get 8684 build).
2. Install it to your desired folder.
3. Play for few minutes or hours to make sure. Also try to change maps, change teams, change classes, etc.

## $\color{Cyan}{[Latest\ Build]}$
1. Buy from Steam store [here](https://store.steampowered.com/app/10/CounterStrike/).
2. Download and install to your desired folder.
3. Play for few minutes or hours to make sure. Also try to change maps, change teams, change classes, etc.
4. Steam version doesn't come with bot option by default. You have to install bot addon yourself or use from ReGameDLL (you'll find it later).

When you done, continue to [MetaHook Installation](Chapter%20I%20-%20B.md) (optional) or [AMX Mod X installation](Chapter%20I%20-%20C.md).
